AG-13Mediummodule-clients.ts.template (externalTarget: 'the client reads no credential'); jeeves-generator READMEAn External API client has no workload-identity credential. A stub that calls a Google API (Web Risk) can only add a header itself; the documented way is a credential from a SECRET_DIR file, i.e. a long-lived API key. On Cloud Run, Link API's Q06 code got 403 from Web Risk and every guest create failed closed (503).Application files: link-operations/google-credentials.ts fetches Link API's service-account token from the metadata server (cached, monotonic, one deadline with the lookup) when QRWTY_REPUTATION_CREDENTIALS=metadata; the production profile requires that value. 9 unit tests.
AG-14Mediummodule-clients.ts.template (httpTarget)Tile-to-tile calls carry no ID token, so Cloud Run's invoker IAM can't protect a service another tile calls: such a service must be internal-only with IAM off, and any VPC caller can reach it. A public origin can be IAM-protected only if no tile calls it (Billing API had to become internal; Stripe webhooks would need it public).IaC: internal ingress with IAM off for Link, Account and Billing API; IAM required for the public Redirect and Session origins (no allUsers).
AG-15Mediumhttp.ts.template (the reserved /healthz route); probe wiringThe generated health route /healthz is a path Cloud Run's front end reserves: <service>.run.app/healthz answers Google's 404 page before the container. Only Cloud Run's own startup and liveness probes reach it, so no edge, uptime check or tile can read a process's health over HTTP.None needed for this deploy (Cloud Run's probes work); P09 used the sign-in me routes to show reachability.
AG-16Mediummodule-clients.ts.template (pubsubPublisher, pubsubLoop: new PubSub without apiEndpoint)The Pub/Sub clients always use the global endpoint and have no regional-endpoint binding. The durable-clicks contract pins storage to us-central1 with in-transit enforcement; Pub/Sub then refuses any request the global endpoint routes to another region (FAILED_PRECONDITION, seen from outside the region). The generated publisher and worker work only because Google routes them to us-central1.None in the app; operators pull dead letters through https://us-central1-pubsub.googleapis.com/. Remedy: JEEVES_PUBSUB_ENDPOINT, required when the topic enforces in transit.
AG-17Lowprocess.ts.template (runProcess)A process logs 'Application ready' but nothing when SIGTERM arrives, when its drain starts or ends, or with what code it exits; Cloud Run logs no exit for a service instance either. A rollout's drain can't be shown from logs (P10).P10 shows the drain by traffic instead: 1,501 requests during the rollout, none failed.
