## Objective

A Cloudflare Worker (Free plan) serves `https://qrwty.io/`. There is no GCP in this unit.

### The page
- One static page, `QRWTY`, with the line "Short links that never lose a click. In development."
- A small build line: short commit, and build time in UTC.
- Inline CSS only, with light and dark from `prefers-color-scheme`.
- No external requests, fonts, scripts or trackers.

### Endpoints
- `GET /healthz` returns `200` with JSON `{"ok":true,"commit":"<sha>","builtAt":"<iso>"}`.
- `GET /build.json` returns the same build object.
- Any other path returns a small HTML `404`.

### Headers on every response
- `Content-Security-Policy: default-src 'none'; style-src 'unsafe-inline'; img-src 'self'; base-uri 'none'; frame-ancestors 'none'`
- `X-Content-Type-Options: nosniff`
- `Referrer-Policy: no-referrer`
- `X-Robots-Tag: noindex` (it's a placeholder)
- **No HSTS yet.** Q13 decides HSTS, because preload is hard to undo.

### `www.qrwty.io`
Answers `301` to `https://qrwty.io/` with the same path.

### Layout and deploy script
- Put everything in `deploy/cloudflare/`: the Worker source (TypeScript), `wrangler.toml`, a
  `package.json` with exact pins and its own `pnpm-lock.yaml`, and `README.md`.
- Pin `wrangler` at an exact version at least two weeks old.
- `deploy/cloudflare/deploy.sh`:
  1. writes the build object from `git rev-parse HEAD` and the current UTC time, refusing a dirty
     tree unless passed `--allow-dirty`;
  2. runs `wrangler deploy`;
  3. checks `/healthz` from this machine and confirms the deployed commit.

  Later units run it to redeploy, so it must be idempotent.

### Hostnames and DNS
1. List the zone's DNS records first and keep a sanitized before-list in the evidence: name, type and
   proxied status. Include content only for A/AAAA/CNAME records, never for TXT.
2. Attach the Worker to `qrwty.io` and `www.qrwty.io` as Custom Domains. If an existing apex or `www`
   record blocks this, you may replace it (the owner authorized changing qrwty.io DNS). Record exactly
   what you removed, so it can be restored.
3. **Never** change MX, TXT, CAA or any other record.
