## Objective

Do Q07 of `docs/plans/production-build/units.md` ("Sessions, ownership and account operations"). It
lives in the application-owned stub bodies and product SQL of Session API, Link API and Account API.
Use pack v1.6's frozen `decisions.md`, `http-contract.md` and `product-contract.md` for the behaviour
and the error contract.

- **Sign-in:** code + PKCE, state and nonce, against **Auth0**.
  - Same-origin `Secure`/`HttpOnly` cookie sessions on qrwty.io, with CSRF protection, expiry,
    revocation and encrypted token storage.
  - Forward a valid bearer token to the downstream guards.
  - Anonymous create keeps working with no token. A token that is supplied but invalid is never
    downgraded to anonymous.
- **Ownership:** atomic claim of a guest link (Q06's claim proof). Owned list, update, disable and
  delete use version preconditions and safe cursor paging. Scoping comes from the verified identity,
  never from a request field.
- **Account:** `GET /api/v1/me` and delete-my-account, following the frozen deletion policy.
- **Public routes:** wire the browser-facing `/api/v1/session`, `/api/v1/links` (create, list and
  the rest) and `/auth/login`, `/auth/callback` and `/auth/logout` through Session API's stubs to
  Link API and Account API.
- **Use today's Jeeves helpers where they remove code:** `defineRoutes`, `signal`, `transaction`,
  `idempotent` and `declareSettings`.

### Auth0

  - rotating refresh tokens;
